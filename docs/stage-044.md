## Frozen scope, model and gates

Implement an offline preparation compiler, not another topology snapshot:
validated canonical build -> bounded physical-region/interface graph -> gas
cell layout plus an executable **lossless frozen-background B0 geometry
control**. Native full-descriptor preparation remains authoritative. Runtime
engine coupling is 045+, component impedance/loss qualification is 049–051,
and browser/3D consumers are later stages. Do not approximate catalysts or
packing with invented tonal filters to make this compiler appear complete.

Include every header, collector storage volume, exhaust pipe, center can/pipe,
link, finite X/Y volume, catalyst interface, muffler/baffle interface and outlet.
Preserve the existing descriptor's modeled dimensions and uncertainty. Compiler
metadata must distinguish measured/published/estimated quantities; unannotated
legacy dimensions default to effective model estimates, not surveyed hardware.
Lumped junction volumes have no newly invented axial path length.

Shared ambient-exhaust logical nodes are environmental labels. Each aperture
gets its own physical terminal: never connect independent banks acoustically
through a zero-delay ambient shortcut. Every physically connected source/port
must have all loop-free paths to every outlet; disconnected pairs are explicit.
Paths list stable component/port identities, ordered orientation, length and
segment areas. These paths describe geometry, not the multiple-reflection
transfer function of a real exhaust.

Freeze before execution:

- All five canonical builds, exact component/port topology and native volume/
  restriction observations. Length/area/volume agreement at relative 1e-10 or
  absolute 1e-12 SI (1e-10 m for path sums); integer identity exact.
- Source/outlet reachability: I4 4, I6 6, cross V8 16, flat V8 8, boxer 8
  reachable cylinder/aperture pairs. I6/flat independent banks must not cross
  via ambient. Cross X and boxer Y must retain both branches.
- For every cylinder source, execute the actual compiled B0 network at 192 kHz
  for 0.15 s. Connected outlet response must be nonzero, disconnected exactly
  zero. No signal before the sum of integer edge delays along the shortest
  path; fractional delays have their explicitly tested interpolation bound.
  Source/storage/terminal balance <=1e-10 relative to source work; no failures.
- Gas preparation allocates all requested cells at unchanged physical lengths,
  preserves all volumes and finite-node inventories, and initializes the
  production EOS. It does not advance rejected A2 through engine junctions.
- Caller-selected 128-component/256-node schema limits plus narrower backend
  node/edge/degree, total gas-cell and path capacities fail in preparation;
  no branch dropping, fake minimum pipe length or enlarged physical cells.
  Full-loss component execution requests fail explicitly pending 049–051.
- Preset spatial placement/centerlines are unresolved. Spatial compilation
  must reject them; explicit synthetic connected bent-centerline fixtures
  must match physical lengths and port coordinates before spatial acceptance.
  This does not certify fabrication geometry or an implemented 3D renderer.
- Mutation/adverse controls detect omitted/crossed branches, altered lengths,
  areas/volumes, source identity/orientation, unsupported capability and
  insufficient capacity. Compare runner omission, field edits and rebuild
  identities. Full affected suites and actual offline results page preserve
  accepted audio, coasts, references and registered research sections.
