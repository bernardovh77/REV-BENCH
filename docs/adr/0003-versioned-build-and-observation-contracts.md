# One complete SI build and generation-tagged observations

Stage 037 implements Bernardo's agreed contracts-first order as a specified
version-1 description and native reference proof. Keep the existing C engine
and TS bindings; use one SI description of every active native field, stable
semantic component/port/source IDs, explicit unresolved spatial data, separate
configuration revision and prepared-state generation, and actual event clocks.
Render/display observations must identify one coherent physical boundary and
an explicit audio epoch. Builds do not serialize native memory or running gas.

The initial rebuild policy requires quiesced audio, full inactive preparation,
one stable-address handle commit and explicit reset/dyno/history acknowledgment.
It does not promise concurrent hot swapping, shared-memory transport or device
synchronization already implemented. Existing internal self-pointers make raw
engine copies or cross-instance WASM pointers invalid. Unknown features,
contradictory logical geometry and stale generations reject.

The [contract](../../contracts/README.md), [runtime rules](../../contracts/runtime-v1.md)
and [Stage 037 proof](../stage-037.md) define the limits. Full geometry compilation,
actual causal event producers, atomic production APIs, worklet lifecycle and 3D
delivery remain separately gated stages. This decision chooses a shared data
contract, not a production acoustic renderer.
